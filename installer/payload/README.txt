Stealth HUD 0.3.1 for Deus Ex: Human Revolution - Director's Cut

A minimal in-game HUD for achievement and stealth conditions: Pacifist, Foxiest of the Hounds, Legend, Ghost and Smooth Operator, plus Factory Zero during The Missing Link.

F9: expanded English descriptions. F10: hide/show. F11: inherited graphics settings.
Requires Windows 10+, the supported Steam DXHRDC.exe and DirectX 11. Original Human Revolution and other executable builds are not supported.

Run StealthHUD-Setup-0.3.1.exe, select the game directory and choose Install. Close the game first. The installer detects Steam libraries, checks the game EXE, includes ASI Loader and preserves existing INI settings. A different winmm.dll is left untouched and blocks automatic installation.

This distribution is a modified DXHRDC-GFX build, not a standalone plugin to load alongside it. An existing DXHRDC-GFX.asi is backed up and replaced. Fresh installs use Director's Cut graphics settings; existing graphics settings are preserved.

To undo, run the same installer and choose Restore previous. The original ASI is restored, or the new ASI is removed if there was no previous plugin. INI files and the shared ASI loader are retained to avoid disrupting other mods. Backups remain archived beside the game. Saves and the game EXE are not edited.

Green: eligible. Red: failed. Amber: different results across active objectives. Grey dash: bonus not applicable. Question mark: unknown/loading. Local bonuses summarize all applicable active objectives, not just the selected quest. Being spotted is not the same as triggering an alarm.

The tracker reads internal condition flags; it does not unlock achievements. Difficulty and kill detection were gameplay-tested. Ghost and bonus availability were read in the live game; full controlled alarm/reload and Factory Zero validation remain incomplete. This is an early public release, not a guarantee of achievement completion.
